# Stack technique

Vue exhaustive et concise des technologies utilisées dans MicroCRM.

## Vue d'ensemble

| Domaine | Technologies |
|---|---|
| Frontend | Angular 17.3, TypeScript 5.4 |
| Backend | Spring Boot 3.x, Java 17 |
| Conteneurisation | Docker |
| CI/CD | GitLab CI/CD |
| IaC | Terraform, Ansible |
| Orchestration | K3s, Helm |
| Cloud | AWS |
| Observabilité | CloudWatch |

## Frontend

- Angular 17.3
- TypeScript 5.4
- Emplacement : `front/`

## Backend

- Spring Boot 3.x
- Java 17
- Emplacement : `back/`

## Infrastructure

- Terraform : provisionnement AWS
- Ansible : configuration des instances et de K3s
- Helm : déploiement applicatif dans K3s
- Emplacement : `infrastructure/`

## CI/CD

- GitLab CI/CD
- Pipeline : `.gitlab-ci.yml`

## Cloud

- AWS

## observabilité

- CloudWatch
